AdManager — своя реклама в bajaj GO
===================================

Положите файлы в папки рядом с игрой, и они начнут появляться на щитах
вдоль трассы вместе с процедурной рекламой. Кнопок в игре нет: всё
подхватывается автоматически при запуске.

Структура
---------

  AdManager/
  ├── billboards/          реклама на обычных щитах: фото и видео
  │   ├── promo1.jpg
  │   ├── sale.webp
  │   └── ролик.mp4
  ├── overheads/           указатели над дорогой: фото и постеры видео
  │   ├── exit_sign_1.png
  │   └── exit_sign_2.jpg
  ├── manifest.json        необязательный список файлов (рекомендуется)
  └── README.txt           этот файл

Что поддерживается
------------------

Картинки: JPG, PNG, WebP. Рекомендуется 16:9, примерно 1280×720.
Соотношение сторон щита — 16:9, поэтому сильно вытянутые картинки
обрежутся по краям.

Видео: MP4 (H.264) или WebM (VP9), без звука. Ограничения:
  • длительность — до 10 секунд;
  • размер файла — до 10 МБ;
  • разрешение — не больше 1024 px по большей стороне;
  • соотношение сторон — 16:9, рекомендуется 1280×720 или меньше.

Файл, который не проходит по лимитам, пропускается: в консоли браузера
появляется предупреждение, игра продолжает работать. Звук у видео всегда
выключен, даже если дорожка в файле есть.

На указателях над дорогой (overheads/) видео не проигрывается — вместо
него показывается первый кадр (постер). Движение видео допускается только
на обычных щитах.

Имена файлов — латиницей или транслитом, без пробелов. Пробелы в именах
лучше заменить на «_»: так файлы гарантированно найдутся на любом сервере.
Регистр расширения не важен: .JPG и .jpg работают одинаково.

manifest.json
-------------

Если файлов немного, список можно не вести: игра попробует прочитать
содержимое папок через сервер. Но на GitHub Pages, в Capacitor и на
многих других хостингах список файлов закрыт. Поэтому надёжнее указать
файлы вручную:

  {
    "version": 1,
    "billboards": ["promo1.jpg", "sale.webp", "ролик.mp4"],
    "overheads": ["exit_sign_1.png", "exit_sign_2.jpg"]
  }

Порядок поиска:
  1. AdManager/manifest.json — если файл есть, используются только
     перечисленные в нём материалы;
  2. автоматический список файлов из папок — если manifest.json нет,
     а сервер отдаёт содержимое каталога;
  3. только процедурная реклама — если не сработало ни то, ни другое.
     В консоли будет одно предупреждение, игра не сломается.

Пустые строки и посторонние файлы в manifest.json игнорируются.
manifest.example.json рядом — образец, его можно скопировать в
manifest.json и отредактировать.

Кэш обнаружения
---------------

Список обнаруженных файлов хранится в sessionStorage под ключом
bajajGO_adManagerDiscovery. При перезагрузке страницы он сбрасывается,
и файлы обнаруживаются заново — отдельно чистить ничего не нужно.
Добавили или заменили файл — просто обновите страницу (можно Ctrl+F5).

Если хочется сбросить кэш вручную:

  sessionStorage.removeItem('bajajGO_adManagerDiscovery');
  location.reload();

Как запустить
-------------

Игре нужен HTTP-сервер: при открытии HTML-файла двойным щелчком (file://)
браузер блокирует чтение manifest.json и папок. Тогда остаётся только
процедурная реклама. Запускайте игру через npm run dev или любой
статический сервер, например python -m http.server.

Для собранного dist/bajaj-go.html папка AdManager/ должна лежать рядом
с HTML-файлом, то есть dist/AdManager/.

Стиль
-----

Реклама должна выглядеть частью игры: воксельная или упрощённая графика,
приглушённые цвета, без кричащего неона. Крупный текст и простой силуэт
читаются на скорости лучше мелких деталей.

Настройки (необязательно)
-------------------------

В консоли браузера можно поменять поведение рекламы:

  localStorage.setItem('bajajGO_adUploadedShare', '0.5'); // доля 0..1
  localStorage.setItem('bajajGO_adEnabled', '0');          // выключить
  location.reload();

bajajGO_adUploadedShare — вероятность показа вашего материала вместо
процедурного. 0 — только процедурная реклама, 1 — только ваша.
bajajGO_adEnabled = '0' полностью отключает AdManager.

Ограничения
-----------

Одновременно могут проигрываться не больше двух видео — только на щитах
впереди, не дальше 120 метров. Остальные щиты показывают постер. Это
сделано, чтобы не просаживать FPS и не перегружать GPU.

Папка AdManager/ не заменяет процедурные текстуры: она добавляет свои
материалы к ним. Существующие бренды и оформление игры остаются на месте.
