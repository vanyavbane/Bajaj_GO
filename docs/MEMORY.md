## Известные проблемы

| Приоритет | Проблема | Где |
|---|---|---|
| 🔴 высокий | **Three.js грузится с CDN.** Без интернета игра не запускается. Блокер для APK и офлайна. | секция 2, строка `import * as THREE from 'https://cdn.jsdelivr.net/...'` |
| 🔴 высокий | **Мобильное управление бедное.** Только 4 кнопки руля + «дальний свет» + «камера». Нет свайпов, наклона, вибрации. Для Android этого мало. | секция 15 |
| 🟠 средний | **Тип `bus` не имеет явной ветки** в `createVehicleModel`. Он попадает в финальный `else`, который одновременно является свалкой для любых неизвестных типов. Добавишь новый тип — молча получишь автобус. | секция 9 |
| 🟠 средний | **Монолит 4000 строк.** Любая правка требует чтения контекста. | весь файл |
| 🟠 средний | **Нет единой воксельной сетки.** Блоки разного масштаба — воксельность читается неравномерно. | секции 6, 9, 10 |
| 🟡 низкий | **Меню показывает закат**, а не ночь: `todCycleTime = 0.385` жёстко задан в `updateAtmosphereAndTimeOfDay`. Референс — ночь. | секция 12 |
| 🟡 низкий | **Нет вибрации** (`navigator.vibrate` не используется) — на телефоне нет тактильной отдачи при аварии. | — |
| 🟡 низкий | **Внутренние переменные недоступны из консоли** (ES-модуль). Отладка только через `debugger`. | — |

## Открытые вопросы

Требуют решения владельца проекта:

1. **Неоновые рампа-маркеры.** `M.neonCyan` / `neonYellow` на рамках и байке Юры
   противоречат принципу «без неона». Заменить на сигнальный янтарный?
2. **Время суток в главном меню.** Оставить закат или сделать ночь, как на обложке?
3. **Экспозиция в режиме «DLSS»** (1.18) — проверить на реальном телефоне,
   не выглядит ли ночь «пыльной».
4. **Рекламные баннеры с изображениями** — планируются; нужно решить, где хранить
   картинки (внутри приложения или загружать), и откуда брать права на контент.
