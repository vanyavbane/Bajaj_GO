# Документация bajaj GO

Единая точка входа. Читать перед любой правкой кода.

| Файл | Что внутри |
|---|---|
| [ARCHITECTURE.md](ARCHITECTURE.md) | Карта кода: секции, ключевые переменные, где что менять |
| [STYLE.md](STYLE.md) | Визуальный стиль, палитра, отклонения от референса |
| [MEMORY.md](MEMORY.md) | Решения, известные баги, открытые вопросы, журнал работ |

## Правила работы с документацией

1. **Перед правкой** — найти нужный раздел в `ARCHITECTURE.md`, чтобы не сломать соседний функционал.
2. **После правки** — обновить затронутые файлы документации и добавить запись в журнал `MEMORY.md`.
3. Если решение меняет архитектуру — сначала записать его в `MEMORY.md` (раздел «Решения»), потом кодить.
4. Документация описывает **намерения и договорённости**, а код — единственный источник истины по реализации.

## Текущее состояние проекта

- Разработка: `npm install`, затем `npm run dev`. Вход `js/main.js`. Типы: `npm run typecheck`.
- Сборка: `npm run build` или `./build` пишет один `dist/bajaj-go.html`. Его можно открыть двойным щелчком.
- Three.js 0.160.0 ставится пакетом `three`. Внешнего CDN нет. `./serve` — запасной сервер после `npm install`.
- Сохранения в `localStorage`.
- Git-репозиторий: https://github.com/vanyavbane/Bajaj_GO (приватный).
