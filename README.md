# bajaj GO

3D-мотогонка в воксельной стилистике на **Three.js**. Разметка и стили — в
`index.html`, логика — ES-модули в `js/`. Имя `index.html` нужно для GitHub
Pages и для упаковки в Android (Capacitor).

## Запуск

Один раз из корня проекта:

```bash
npm install
```

Дальше, для разработки:

```bash
npm run dev
```

Vite поднимает страницу на порту 5173 и обновляет её при сохранении файлов.
`import 'three'` берётся из пакета `three@0.160.0`. Двойной щелчок по
`index.html` не сработает: браузер не грузит ES-модули с `file://`.

Проверка типов: `npm run typecheck`. Известные поля общего состояния описаны в
`js/game-state.d.ts`, остальное пока `any`.

Запасной сервер без Vite, если зависимости уже установлены:

```bash
./serve
```

Он тоже слушает 5173, не кэширует файлы и перезагружает вкладку целиком, когда
меняется `index.html`, `css/` или `js/`.

Готовый файл без сервера:

```bash
npm run build
```

или `./build`. Появится `dist/bajaj-go.html`: стили, игра и Three.js уже внутри,
файл открывается двойным щелчком. Править нужно исходники, потом собрать заново.

## Визуальный стиль

Референс: `Cover art.bmp` (обложка, 1842×854).

- **Геометрия:** воксельная / блочная, гранёная. Никакого сглаживания «под реализм».
- **Палитра:** тёмная, холодная, ночная.
  Основные тона: `#181830`, `#303030`, `#486090`, `#181818`, `#303048`,
  акценты: `#183018` (тёмно-зелёный), `#303018` (хаки), `#483030` (тёмно-коричневый).
- **Время суток:** в игре есть смена суток; референс — ночь.
- **Свет:** без неона. Фонари, фары, уличное освещение. Цветные акценты допустимы,
  но приглушённые.
- **Текстуры:** сейчас нет, всё заливками. В планах — рекламные баннеры с изображениями.
- **Мотоцикл:** воксельные Bajaj Pulsar, Boxer и Avenger, основной вид — от первого лица.

## Мотоциклы

В магазине 14 машин, карточки идут от медленной к быстрой. Стартовый байк
нового игрока — бесплатный **Boxer 100 ES**, Pulsar NS125 стоит 850 ₽.
Полный список: Pulsar NS125 / NS200 / N250, Dominar 400 / 1000RR / 250, Qute,
Qute Юры Волкова, Boxer 100 ES / 125 / 150, Pulsar 150 NS / 180 NS и Avenger 220.

Цены: Boxer 100 ES — 0 ₽, Boxer 125 — 700 ₽, Boxer 150 — 850 ₽,
Pulsar NS125 — 850 ₽, Pulsar 150 NS — 900 ₽, Pulsar 180 NS — 950 ₽,
Pulsar NS200 — 1200 ₽, Avenger 220 — 1020 ₽, Dominar 250 — 1600 ₽.

- **Boxer** — простой обвес: одна круглая фара, хром-бак, плоское сиденье,
  овальная задняя фара.
- **Avenger 220** — отдельная модель чоппера: низкое сиденье, длинная вилка,
  sissy bar, хром-дуги и длинный выхлоп. Камера кокпита по умолчанию 78° / +0.15 м.
- **Приборка** зависит от байка: у Boxer'ов и Avenger — аналоговый круглый
  спидометр с одометром, у Pulsar/Dominar — цифровая панель.
- **Тюнинг** общий на все модели: купленные улучшения видны и на новых байках,
  всё сохраняется в `localStorage`.

## Прыжки и Slow-Mo

- На трассе есть трамплины. В прыжке считается число перелетённых машин,
  дистанция и бонус; плашка `#jump-live` показывает их на лету.
- Перелёт через **3 машины** за один прыжок включает Slow-Mo: мир плавно
  замедляется до 40%, появляются виньетка и бейдж, звук входит низким тоном.
  Управление и физика продолжают работать, бонусы и комбо не сбрасываются.
- Эффект срабатывает один раз за прыжок. При приземлении или ДТП время плавно
  возвращается к обычному; страховка — 6 секунд.
- Камера кокпита настраивается отдельно для каждого мотоцикла: FOV 60–110°
  и высота −1.5…+1.5 м, с живым предпросмотром. Открывается кнопкой ⚙ в
  главном меню или из паузы. Третье лицо фиксировано (FOV 75°).

## Погода

- Во время заезда случайно начинается дождь. Первый эпизод — через 30–60 с,
  длится 25–65 с; следующие — не раньше чем через 90 с после предыдущего.
  В меню, гараже, магазине и паузе дождь не идёт, таймеры стоят.
- Дождь воксельный: пул тонких капель в одном `InstancedMesh`, наклон по
  направлению движения, без создания объектов в кадре.
- Тучи сгущаются за 3–5 с, темнеют и опускаются; цвет зависит от времени
  суток (день — серо-синий, закат — багровый, ночь — почти чёрный). После
  дождя так же плавно рассеиваются.
- Небо и туман темнеют, дымка усиливается, свет становится мягче. Дорога
  мокнет: сильнее отражения, ночью ярче фары и фонари; затем асфальт
  постепенно высыхает. На мокрой дороге тормозной путь немного длиннее.
- Редко — 1–2 вспышки молний с раскатом грома. Дождь звучит тихим фоном и
  не перекрывает игровые звуки.

## Пост-эффекты

- Главное меню: кнопка «⚙ Настройки» открывает экран с вкладками «Графика»,
  «Освещение», «Вид камеры» и «Звук» (пока пустая). В паузе те же настройки
  доступны отдельными пунктами.
- **Motion Blur** — лёгкое кинематографичное размытие окружения на скорости.
  Проявляется от ~35 % максималки (≈80 км/ч), сильнее по краям, центр и полосы
  сверху/снизу остаются чёткими. Мотоцикл, приборка и HUD не размываются.
  Настройки: включение, интенсивность 0–100 % и режим «Уменьшить укачивание».
- **God Rays** — световые лучи от солнца. Видны днём и на закате, когда солнце
  в кадре и небо не закрыто тучами; автоматически гаснут в дождь, ночью и в
  тоннеле и плавно возвращаются при ясной погоде. Настройки: включение,
  интенсивность и длина лучей.
- На слабых устройствах и при падении FPS эффекты автоматически слабеют или
  отключаются. Настройки сохраняются в браузере.

## Съезды и экономика

- На трассе каждые 300–800 м появляются съезды к точкам интереса: рестораны,
  АЗС, СТО, тюнинг. Кнопки нет: заезжай в светящуюся коробку медленнее 50 км/ч.
  Карточка впереди зелёная, если скорость уже подходит, и красная, если надо
  тормозить. Быстрее 50 коробку можно проехать.
- Перед съездом на полосе светится маркерная зона: **зелёная** — рестораны,
  **жёлтая** — АЗС/СТО/тюнинг. Пока щит впереди, сверху видны сторона, метры
  и кнопка. Въезд в коробку даёт вспышку и звук.
- **Доставка:** в ресторане берётся заказ (150–760 м, 30–120 с). Награда зависит
  от расстояния и оставшегося времени, при просрочке — штраф.
- **Топливо:** бака хватает на 25 000 м. Пустой бак — эвакуатор за 1000 ₽ или
  езда 5 км/ч до аварийной АЗС.
- **Износ:** колодки, масло и свечи изнашиваются с пробегом и ухудшают торможение,
  динамику и максимальную скорость. Меняются на СТО.
- **Тюнинг:** доступен через съезд «Тюнинг» на трассе (в главном меню кнопки нет).
- **ДТП:** с активным заказом можно вызвать скорую за 250 ₽ и продолжить заезд.
- **Пауза:** Esc / P или кнопка ⏸. Таймеры и симуляция замирают. В настройках
  паузы можно переключить вид камеры и открыть настройки кокпита.

## Технические заметки

- Three.js зафиксирован пакетом `three@0.160.0` (лицензия MIT). В разработке его
  подключает Vite, в `dist/bajaj-go.html` он уже внутри файла.
- Сохранения — `localStorage`: `bajajGO_bank`, `bajajGO_owned`, `bajajGO_selected`,
  `bajajGO_colors`, `bajajGO_tuning`, `bajajGO_lighting`, `bajajGO_camera`,
  `bajajGO_camprofiles`, `bajajGO_fuel`, `bajajGO_wear`, `bajajGO_limp`,
  `bajajGO_order`, `bajajGO_motionBlur`, `bajajGO_motionBlurIntensity`,
  `bajajGO_motionBlurComfort`, `bajajGO_godRays`, `bajajGO_godRaysIntensity`,
  `bajajGO_godRaysLength`.
- Оформление интерфейса — пакет `@bajajgo/design` (`packages/design`). Экраны
  собираются из его элементов: кнопка, панель, меню, список, заголовок. Цвета
  лежат в том же пакете как переменные `--ds-*`.
- Графика настраивается в меню и в паузе: режим, тени, масштаб кадра, фонари.
  Отражения и пост-эффекты — на вкладке «Освещение».
- Рендер: WebGL, ACES Filmic, тени PCF вокруг мотоцикла. Есть экран ошибки при
  отсутствии WebGL.
- Снимок 3D-сцены: `npm run scene`. В разработке сцена доступна как `window.__bajaj`
  (положение, скорость, вызовы отрисовки, ошибки). В собранном файле то же открывается
  адресом с `?debug`. Отдельной панели на экране нет.

## План: Android / Google Play

- Упаковка через **Capacitor** (ассеты внутрь приложения, игра работает офлайн).
- В Play загружается **AAB**, не APK.
- Требование Google Play: **targetSdk 36 (Android 16)** для новых приложений
  (с 31.08.2026).
- **Keystore хранится вне git.** Потеря = невозможность обновлять приложение.
- Рекламные баннеры с изображениями: права на картинки должны быть свои или
  лицензионные, иначе приложение снимут по жалобе.
