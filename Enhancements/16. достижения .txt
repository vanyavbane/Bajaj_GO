# Промпт для GLM-5/3 Flash Free — система «Достижения»

## Контекст

Игра «bajaj GO» на Three.js (файл `bajaj-go.html`, минифицирован). Есть главное меню с кнопками, настройки, биомы (`Набережная`, `Лес`, `Город`, `Горы`, `МКАД`), мотоциклы (покупка/смена), СТО (ремонт), бензин/эвакуатор, доставки, комбо, развязки (fork, выбор поворота налево/направо), полёт (полёт на мотоцикле), прогресс сохраняется (вероятно `localStorage`). Нужно добавить экран «Достижения» с 17 достижениями, у числовых — 5 уровней (I–V). Каждое достижение — **со своим значком (иконкой), соответствующим названию**, и **в виде плиток (карточек)** в сетке.

**Код минифицирован** — ищи по смыслу: `menu`, `mainMenu`, `button`, `screen`, `biome`, `distance`, `odometer`, `combo`, `repair`, `service`, `fuel`, `gas`, `tow`, `truck`, `delivery`, `courier`, `bike`, `motorcycle`, `purchase`, `speed`, `maxSpeed`, `fork`, `turn`, `left`, `localStorage`, `save`, `load`, `progress`.

---

## Общие требования

1. **Не ломать существующую логику** — достижения только **читают** существующие счётчики/события, не меняя поведение игры. Где счётчиков нет — добавить инкремент в существующем месте (аккуратно, якорями), не дублируя логику.
2. **Сохранение** — прогресс достижений в `localStorage` вместе с остальным сейвом (тот же объект/ключ; добавить секцию `achievements`). Загрузка при старте, миграция: если секции нет — создать с нулями.
3. **UI** — экран «Достижения» в стиле существующих экранов (шрифт, отступы, цвета, тач-поведение). Кнопка «Достижения» в главном меню — рядом с существующими кнопками, в том же стиле.
4. **Производительность** — экран достижений обновлять только при открытии/изменении, не в `requestAnimationFrame`.
5. **Сброс** — если есть «сброс прогресса» — достижения тоже сбрасываются (или отдельная кнопка, уточнить; по умолчанию — вместе с общим сбросом).

## Значки и плитки (новое требование)

- **У каждого достижения — свой значок (иконка), соответствующий названию.** Значок должен визуально отражать суть достижения, например:
  - «Лётчик» — самолёт / крыло / шлем лётчика;
  - «В притирку» — сжатые кулаки / молния / «combo»-звезда;
  - «Официальный диллер» — гаечный ключ / вывеска СТО / шестерёнка;
  - «Расчётливый» — эвакуатор / монета + эвакуатор;
  - «Сэкономил — заработал» — монета / кошелёк / перечёркнутый эвакуатор;
  - «Коллекционер» — мотоцикл / гараж / коллекционная полка;
  - «Успешный курьер» — коробка/посылка / сумка курьера;
  - «Дальнобойщик» — грузовик / дорога / одометр;
  - «Питербуржец» — разводной мост / набережная / шпиль;
  - «Лесник» — дерево / ёлка / лист;
  - «Нарушитель спокойствия» — город / многоэтажки / сирена;
  - «Горец» — горы / вершина / флаг на пике;
  - «МКАД-ый воин» — кольцевая дорога / кольцо / знак МКАД;
  - «Путешественник» — глобус / компас / чемодан;
  - «Бл#ь я второй» — спидометр / стрелка / пламя скорости;
  - «Ходок» — стрелка влево / указатель поворота.
- **Реализация значков:** использовать **встроенные SVG/эмодзи/иконки** (если в проекте есть иконочный шрифт — использовать его; иначе — inline SVG или эмодзи как fallback). **Не тянуть внешние библиотеки иконок без необходимости** — если в бандле уже есть что-то подходящее, использовать; иначе — простые inline SVG/эмодзи, чтобы не раздувать бандл и не ломать офлайн. Значок хранить в объекте достижения (`icon` — строка SVG/эмодзи/имя иконки).
- **Расположение — плитками (карточками) в сетке.** Не вертикальный список, а **grid из плиток** (например, 2 колонки на мобильном, 3–4 на широком экране — адаптивно, `CSS grid`, `auto-fill`/`auto-fit` с `minmax`). Каждая плитка:
  - значок (сверху/слева),
  - название,
  - краткое описание,
  - прогресс (уровень I–V + значение/порог, или «Открыто/Не открыто»),
  - визуальное состояние: открыто/в процессе/закрыто (например, приглушённая плитка для уровня 0).
- Плитки должны корректно скроллиться, не ломать тач, не вылезать за экран (учёт `viewport-fit=cover`, safe-area).

## Модель данных

Одно достижение — объект:

```
{
  id: string,            // уникальный ключ, например 'pilot'
  title: string,         // 'Лётчик'
  description: string,   // пояснение
  icon: string,          // SVG/эмодзи/имя иконки, соответствует названию
  type: 'counter' | 'boolean',
  value: number,         // текущее накопленное значение (для counter)
  level: number,         // 0..5 (0 = не открыто, 1..5 = I..V) для counter
  unlocked: boolean      // для boolean (посещены все биомы и т.п.)
}
```

- **counter** — числовое достижение: есть 5 уровней (I–V), значение растёт, уровень = порог. В UI показывать римскую цифру **I, II, III, IV, V** (не арабскую). Если уровень 0 — показывать «—» или пустой индикатор (уточнить у меня; по умолчанию — «—»).
- **boolean** — одноразовое (например, «Путешественник» — посетить все биомы): либо открыто (галочка), либо нет.

Пороги уровней — **подобрать под масштаб игры** (пробег в км, комбо в единицах, количество раз и т.п.). Сделать **константами в одном месте** (`ACHIEVEMENT_THRESHOLDS`), чтобы легко менять. Пример (подставить реальные значения после уточнения):
- Пробег (км): 10 / 50 / 200 / 1000 / 5000 (для «Дальнобойщик»); для биомных — пропорционально меньше.
- Комбо: 5 / 15 / 30 / 60 / 100.
- Ремонты/эвакуатор/отказы/доставки/покупки/левый поворот: 1 / 5 / 15 / 50 / 100.
- Макс. скорость (км/ч): 60 / 80 / 100 / 120 / 150 (или реальные пороги игры).
- Полёт (м/км): по масштабу игры.
**Если не уверен в порогах — вынеси в константы с комментарием `// TODO: подобрать` и явно перечисли их в ответе, чтобы я поправил.**

## Список достижений (17)

### Числовые (5 уровней I–V)

1. **«Лётчик»** (`pilot`) — суммарное расстояние, которое игрок преодолел **в полёте** (на мотоцикле в воздухе). Накопительное, по всем мотоциклам. Счётчик: накапливать дистанцию полёта (уже есть логика полёта — найти и добавить инкремент в момент приземления/в полёте, не дублируя).
2. **«В притирку»** (`closeCall`) — **максимальное накопленное комбо** за всё время (не сумма, а максимум). Счётчик: при каждом обновлении комбо — `maxCombo = max(maxCombo, currentCombo)`.
3. **«Официальный диллер»** (`dealer`) — сколько раз игрок заезжал на **СТО** и **производил ремонт**. Счётчик: инкремент при завершении ремонта (не при входе).
4. **«Расчётливый»** (`towCalled`) — сколько раз кончался бензин и игрок **вызывал эвакуатор**. Счётчик: инкремент при вызове эвакуатора.
5. **«Сэкономил — заработал»** (`towRefused`) — сколько раз кончался бензин и игрок **отказывался** от эвакуатора. Счётчик: инкремент при отказе (после события «бензин кончился»).
6. **«Коллекционер»** (`collector`) — сколько **мотоциклов куплено** у игрока (покупки в магазине). Счётчик: инкремент при успешной покупке мотоцикла.
7. **«Успешный курьер»** (`courier`) — количество **успешных доставок**. Счётчик: инкремент при успешном завершении доставки.
8. **«Дальнобойщик»** (`trucker`) — **общий пробег** по всем биомам (сумма). Счётчик: накапливать общий одометр (по всем мотоциклам).
9. **«Питербуржец»** (`petersburger`) — пробег по биому **«Набережная»** (общий на всех мотоциклах).
10. **«Лесник»** (`forester`) — пробег по биому **«Лес»**.
11. **«Нарушитель спокойствия»** (`disturber`) — пробег по биому **«Город»**.
12. **«Горец»** (`mountaineer`) — пробег по биому **«Горы»**.
13. **«МКАД-ый воин»** (`mkadWarrior`) — пробег по биому **«МКАД»**.
14. **«Бл#ь я второй»** (`speedDemon`) — **максимальная скорость**, которую набирал игрок (учитывать **любой** мотоцикл). Счётчик: `maxSpeed = max(maxSpeed, currentSpeed)`.
15. **«Ходок»** (`leftTurner`) — сколько раз игрок **выбрал на развязке поворот налево**. Счётчик: инкремент при выборе левого поворота на fork.

### Одноразовое (boolean)

16. **«Путешественник»** (`traveler`) — **посетить все биомы** (Набережная, Лес, Город, Горы, МКАД). Хранить `Set` посещённых биомов; при посещении нового — добавить; когда все 5 — `unlocked = true`.

> Примечание: «Бл#ь я второй» в списке один раз — считаем его числовым (макс. скорость). Если имелся в виду отдельный boolean-дубль — уточнить.

## Что нужно найти и куда добавить инкременты

| Достижение | Где искать | Что сделать |
|---|---|---|
| Лётчик | логика полёта (`fly`, `air`, `jump`, `land`) | накапливать дистанцию в полёте |
| В притирку | комбо (`combo`, `multiplier`) | `maxCombo = max(...)` при обновлении |
| Диллер | СТО (`service`, `repair`, `sto`) | инкремент при завершении ремонта |
| Расчётливый / Сэкономил | бензин (`fuel`, `gas`, `empty`, `tow`, `evacuator`) | инкремент при вызове / отказе |
| Коллекционер | магазин (`shop`, `buy`, `purchase`, `bike`) | инкремент при покупке мотоцикла |
| Курьер | доставка (`delivery`, `courier`, `order`) | инкремент при успехе |
| Дальнобойщик / биомные | одометр (`distance`, `odometer`, `biome`) | суммировать общий и по биомам |
| Скорость | скорость (`speed`, `maxSpeed`) | `maxSpeed = max(...)` |
| Ходок | fork (`fork`, `turn`, `left`, `choice`) | инкремент при выборе влево |
| Путешественник | смена биома (`biome`, `setBiome`, `transition`) | `Set` посещённых, проверка на все 5 |

Если счётчик уже существует — **переиспользовать**, не создавать дубль. Если нет — добавить поле в объект прогресса и инкремент в указанном месте (якоря до/после).

## UI экрана «Достижения» (плитки)

- Кнопка **«Достижения»** в главном меню (в стиле существующих кнопок).
- Экран — **сетка плиток** (CSS grid, адаптивно: 2 колонки на мобильном, 3–4 на широком; `auto-fill`/`auto-fit` + `minmax`), скролл при переполнении.
- Каждая плитка (карточка):
  - **значок** (свой, по названию — см. раздел «Значки и плитки»),
  - **название**,
  - **краткое описание**,
  - **прогресс**: у числовых — уровень римской цифрой **I / II / III / IV / V** (если 0 — «—»), текущее значение и порог следующего уровня (например, `1 250 / 2 000 км`), опционально полоска прогресса; у boolean — «Открыто» / «Не открыто» (галочка/замок).
  - визуальное состояние плитки: открыто / в процессе / закрыто (приглушённая для уровня 0).
- Плитки не должны ломать тач, вылезать за экран (safe-area, `viewport-fit=cover`), корректно скроллиться.
- Обновлять при открытии экрана (и при возврате из игры), не в игровом цикле.
- Сохранять в `localStorage` (секция `achievements`), грузить при старте, мигрировать при отсутствии.
