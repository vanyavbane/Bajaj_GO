# Единый промпт: полная переработка UI игры bajaj GO в стиле Battlefield 3 + мобильная оптимизация

Ниже — сводный промпт. Отдать дизайнеру/разработчику или ИИ-агенту как единое ТЗ.

---

## 🎯 ОБЩАЯ ЗАДАЧА

Переработать **весь пользовательский интерфейс** игры `bajaj GO` (файл `bajaj-go.html`) в едином визуальном стиле **Battlefield 3**: строгий, «военный», тактильный, с тонкими рамками, скошенными углами, полупрозрачными тёмными подложками, холодным голубым акцентом и жёлто-оранжевым «сигнальным» цветом.

**Важно:** фон (3D-сцена с едущим мотоциклом) **не трогать**. Меняются только кнопки, панели, уведомления, спидометр, HUD и модальные окна.

Логотип игры **в главном меню оставить как есть**. **Во время заезда логотип убрать полностью** (сейчас он висит в левом верхнем углу — удалить).

Дополнительно: **оптимизировать интерфейс под вертикальный мобильный телефон** — сейчас иконки и элементы наезжают друг на друга, такого быть не должно.

## 🎨 ДИЗАЙН-ТОКЕНЫ (обязательно к соблюдению)

### Цвета

| Токен | HEX | Назначение |
|---|---|---|
| `--bf-bg-panel` | `#0b0f14` | Основная подложка панелей (непрозрачная база) |
| `--bf-bg-overlay` | `rgba(10, 14, 20, 0.78)` | Полупрозрачная подложка модалок |
| `--bf-bg-overlay-blur` | `rgba(10, 14, 20, 0.62)` | То же + `backdrop-filter: blur(6px)` |

| `--bf-line-strong` | `rgba(150, 200, 230, 0.65)` | Рамка активного элемента / фокуса |
| `--bf-accent` | `#6fc3e8` | Голубой акцент (иконки, активные табы, прогресс) |
| `--bf-accent-dim` | `rgba(111, 195, 232, 0.18)` | Подсветка активной кнопки |
| `--bf-signal` | `#f0b429` | Жёлто-оранжевый «сигнальный» (важные цифры, рубли, предупреждения) |

| `--bf-ok` | `#7fc97f` | Успех (заказ доставлен, деталь куплена) |
| `--bf-text` | `#e8eef5` | Основной текст |
| `--bf-text-dim` | `#8fa3b8` | Вторичный текст |
| `--bf-text-mute` | `#5d7186` | Отключённый текст / подписи |

### Типографика

- Шрифт: `"Bahnschrift", "DIN Alternate", "Roboto Condensed", system-ui, sans-serif` — узкий, индустриальный.
- Заголовки: `font-weight: 700`, `letter-spacing: 0.08em`, `text-transform: uppercase`.
- Цифры (спидометр, рубли, таймеры): `font-variant-numeric: tabular-nums`, моноширинный `"JetBrains Mono", "Consolas", monospace`.
- Базовый размер в кнопках: `13px`; подписи: `11px`; заголовки секций: `14–16px`.

### Геометрия и прозрачность

- Радиус скругления: **2px** (почти острые углы) — ключевая черта BF3.
- **Скошенный правый-верхний угол** у кнопок и панелей через `clip-path` (срез `8px`) — опционально, но обязательно для primary-кнопок.
- Прозрачность обычных панелей: **0.78**; активных/модальных: **0.62 + blur**.
- Прозрачность кнопки в покое: **0.85**; hover: **1.0**; active: **0.95**.
- Толщина рамки: **1px**; у активного элемента — **1px** с цветом `--bf-line-strong` + внутренняя подсветка `inset 0 0 0 1px rgba(111,195,232,.15)`.
- Тень: `0 4px 12px rgba(0,0,0,.55)` у модалок, у кнопок — без тени (плоский стиль).

## 🧩 КОМПОНЕНТЫ (переработать полностью)

### 1. Кнопка (`.ds-button`, `.ds-icon-button`)

```
Фон:          rgba(15, 22, 30, 0.85)
Рамка:        1px solid var(--bf-line)
Радиус:       2px
Паддинг:      10px 16px
Текст:        uppercase, 13px, 700, letter-spacing .08em, var(--bf-text)
Иконка:       16px слева, gap 10px, цвет var(--bf-accent)
Hover:        фон #121a24, рамка var(--bf-line-strong), лёгкий сдвиг текста (translateX 2px)
Active:       фон #0f1620, рамка var(--bf-accent), внутренний inset-shadow голубой
Disabled:     opacity .4, cursor not-allowed
```

**Primary-кнопка** (старт, купить, продолжить): фон `rgba(111,195,232,0.12)`, рамка `var(--bf-accent)`, текст `var(--bf-accent)`, при hover — заливка `rgba(111,195,232,0.22)`. Скошенный угол `clip-path: polygon(0 0, calc(100% - 10px) 0, 100% 10px, 100% 100%, 0 100%)`.

**Danger-кнопка** (закончить заезд, сбросить): рамка и текст `var(--bf-danger)`, hover-заливка `rgba(225,91,85,0.15)`.

### 2. Панель / модальное окно (`.ds-panel`)

```
Фон:           var(--bf-bg-overlay-blur) + backdrop-filter: blur(6px)
Рамка:         1px solid var(--bf-line)
Радиус:        2px
Паддинг:       20px 22px
Тень:          0 4px 24px rgba(0,0,0,.6)
Заголовок:     uppercase, 16px, 700, letter-spacing .1em, var(--bf-text)
                + горизонтальная линия-разделитель var(--bf-line) под ним
Kicker:        11px, uppercase, letter-spacing .16em, var(--bf-text-dim)
```

### 3. Табы (`.ds-tabs` / `.ds-tab`)

Активный таб: фон `var(--bf-accent-dim)`, рамка `var(--bf-accent)`, текст `var(--bf-accent)`. Неактивный: прозрачный, текст `var(--bf-text-dim)`, при hover — текст `var(--bf-text)`. Разделитель под табами — `1px solid var(--bf-line)`.

### 4. Поля ввода, слайдеры, переключатели

- **Range slider:** трек 4px высотой, цвет `rgba(120,160,190,.3)`, заполненная часть `var(--bf-accent)`, ползунок — квадрат 14×14 с рамкой `var(--bf-accent)`, фон `#0b0f14`. Никаких круглых ползунков.
- **Чекбокс:** квадрат 16×16, рамка `var(--bf-line-strong)`, при checked — заливка `var(--bf-accent)` + галочка тёмная.
- **Сегментированный выбор (`.ds-seg`)**: кнопки в ряд, активная — как primary-кнопка, разделитель 1px между ними.

## 📋 ЭКРАНЫ

### А. Главное меню

- Панель слева (или по центру — на усмотрение), фон `--bf-bg-overlay-blur`.
- Кнопки: **Начать заезд** (primary, самая крупная, 48px высотой), **Магазин мотоциклов**, **Настройки** — обычные.
- Баланс: крупно, `var(--bf-signal)`, моноширинный, справа-сверху панели, с подписью «БАЛАНС».
- Биом-полоса (`.biome-strip`): тонкая рамка `--bf-line`, прогресс-бар `var(--bf-accent)`, иконка + название uppercase.
- **Логотип bajaj GO — оставить как есть** (не переделывать).
- Иконки-инструменты (камера, полный экран) в правом нижнем углу — квадратные 40×40, рамка `--bf-line`.

### Б. Настройки (все вкладки: Графика, Освещение, Камера, Управление, Звук)

- Единый каркас: заголовок «НАСТРОЙКИ» + табы + контент + кнопка «НАЗАД».
- Каждый блок настройки (`.cam-slider-block`) — панель с рамкой, заголовок-строка слева, значение справа `var(--bf-signal)` моноширинным.
- Сегменты (Быстро/Ровно/Чётко, Тени и т.д.) — как `.ds-seg` выше.
- **Предпросмотр камеры** (`.cam-preview-wrap`): рамка `--bf-accent`, фон чёрный, метка «LIVE · КОКПИТ» в левом верхнем углу на полупрозрачной подложке `rgba(0,0,0,.7)`.
- **Вкладка «Управление»:** карточки «Кнопки» и «Акселерометр» — квадратные, рамка `--bf-line`, активная — рамка `--bf-accent` + заливка `--bf-accent-dim`.

### В. Магазин мотоциклов

- Карточка мотоцикла (`.ds-card`): прямоугольник с рамкой, слева название + мета-теги, справа цена/кнопка.
- Активная карточка (выбранный байк): рамка `var(--bf-accent)`, левая вертикальная полоса 3px `var(--bf-accent)`.
- Теги (`.ds-tag`): прямоугольные, 2px радиус, фон `rgba(255,255,255,.06)`, текст 10px uppercase. «Куплен» — `--bf-ok`, «Цена» — `--bf-signal`.
- Свотчи цветов — квадраты 20×20 с рамкой 1px, активный — рамка 2px `#fff`.

### Г. Тюнинг / СТО / Рестораны / АЗС / Эвакуатор

Все эти окна — **одинаковый каркас**: заголовок + баланс справа + список карточек + кнопка «Продолжить путь».

- **Карточка тюнинга:** слева иконка в квадрате 40×40 с рамкой, по центру название (bold) + эффект (`--bf-accent` моноширинный) + описание (`--bf-text-dim`, 12px), справа цена + кнопка. Установленная деталь — рамка `--bf-ok`, метка «УСТАНОВЛЕНО».
- **СТО:** строки-кнопки (`.ds-list`) с иконкой, названием детали, полосой ресурса (`--bf-ok` / `--bf-signal` / `--bf-danger` в зависимости от %), ценой. Недоступная — приглушена, надпись «НОРМА».
- **Рестораны / АЗС:** панель с крупным заголовком-названием, статусом (активный заказ / бак полон), балансом, кнопкой действия (primary / danger) и кнопкой «Продолжить путь».
- **Эвакуатор (критическое окно):** красная рамка `--bf-danger`, заголовок «БЕНЗИН ЗАКОНЧИЛСЯ», две кнопки — «ЭВАКУАТОР (500 ₽)» (primary) и «ЕХАТЬ СВОИМ ХОДОМ» (обычная). Прозрачность подложки 0.85, чтобы читалось поверх сцены.

### Д. Пауза

- Компактная панель по центру, сетка статистики (`.ds-stats`) — 2 колонки, подписи `--bf-text-dim` 10px uppercase, значения `--bf-signal` моноширинным.
- Настройки в паузе — те же компоненты, что и в главном меню.
- Кнопки: «ПРОДОЛЖИТЬ» (primary), «В ГЛАВНОЕ МЕНЮ» (обычная), «НАСТРОЙКИ» (обычная).

### Е. Экран аварии

- Панель с красной рамкой `--bf-danger`, заголовок «АВАРИЯ».
- Статистика: дистанция, перелёты, заработано (`--bf-signal`), баланс.
- Две кнопки: «ИГРАТЬ СНОВА» (primary), «В ГЛАВНОЕ МЕНЮ».

## 🔔 УВЕДОМЛЕНИЯ ВО ВРЕМЯ ЗАЕЗДА (event-feed)

**Полностью переработать** внешний вид всплывающих плашек при объезде, перелёте, комбо, жёсткой посадке, снятии/установке тюнинга.

Стиль: **тонкая панель BF3**, не «пузырь».

```
Фон:            rgba(10, 14, 20, 0.82)
Рамка:          1px solid <цвет типа>
Радиус:         2px
Паддинг:        6px 12px
Текст:          12px, 700, uppercase, letter-spacing .06em
Позиция:        центр сверху (или слева/справа по стороне объезда)
Анимация:       fade + slide вверх 8px, life 2.6s
```

Цвета рамки и текста по типу:
- **Объезд / комбо** — `--bf-accent` (голубой).
- **Перелёт над машиной** — `--bf-signal` (жёлто-оранжевый), плюс `+N ₽` моноширинным.
- **Жёсткая посадка** — `--bf-danger`.
- **Куплено/установлено** — `--bf-ok`.
- **Просрочка/штраф** — `--bf-danger`, текст «ШТРАФ −X ₽».
- **Заказ доставлен** — `--bf-ok`, текст «+X ₽ НА БАЛАНС».
- **Смена биома** — `--bf-accent` с иконкой биома.

Уведомление **«ВСТРЕЧКА ×2»** — компактная плашка `--bf-danger` в верхнем правом углу, квадратная, 2px радиус.
Уведомление **«ДАЛЬНИЙ СВЕТ»** — плашка `--bf-accent`, гаснет через 0.4с.
Индикатор **«SLOW-MO»** — плашка в центре снизу, рамка `--bf-accent`, пульсация opacity.

## 📱 МОБИЛЬНАЯ ОПТИМИЗАЦИЯ UI (вертикальная ориентация, `max-width: 680px` и `orientation: portrait`)

### Проблема

На вертикальном телефоне элементы интерфейса **наезжают друг на друга**: иконки, бейджи баланса, кнопки, теги, свотчи, спидометр, блок состояния мотоцикла перекрываются и выглядят «слипшимися». Это недопустимо — **каждый элемент должен иметь собственное неперекрывающееся место**, либо корректно переноситься на новую строку / скроллиться.

### Общие правила для мобильного UI

1. **Никакого абсолютного наложения.** Все плашки (баланс, бейджи, таймеры, кнопки) на мобильном должны либо:
   - иметь `position: static` / `relative` и участвовать в потоке flex/grid, **или**
   - иметь явно рассчитанные `top/left/right/bottom` без пересечения с другими фиксированными элементами (проверить на высотах 568px, 667px, 740px, 812px, 896px).
2. **Меню главного экрана** — `display: flex; flex-direction: column; gap: 12px;`, панель на всю ширину (`width: 100%; max-width: 100vw; padding: 14px;`). Кнопки — `width: 100%`, высота **не меньше 44px** (тач-таргет). Логотип, бейдж «Выбран: …», биом-полоса, стопка кнопок, баланс — **строго вертикально**, без `position: absolute`.
3. **Баланс в меню** — вынести в отдельную строку **над** кнопками (или под ними), `width: 100%`, `display: flex; justify-content: space-between; align-items: center;`, `font-size: 15px`. Не позволять балансу «наезжать» на иконки-инструменты в углу — иконки-инструменты перенести в отдельный ряд **под** балансом либо **над** ним, `display: flex; gap: 8px; justify-content: flex-end;`, каждая иконка 40×40.
4. **Все `.ds-card`** — `flex-direction: column;` (карточки магазина, тюнинга, СТО), aside (цена+кнопка) — `width: 100%; flex-direction: row; justify-content: space-between; align-items: center;` и **переносится под** основной контент.
5. **Все `.ds-seg`** (сегментированные кнопки) — `flex-wrap: wrap;`, каждая кнопка `flex: 1 1 calc(50% - 6px)` (2 в ряд) или `100%`, если текст длинный. Убедиться, что текст не вылезает за рамку: `white-space: normal; word-break: break-word; min-width: 0;`.
6. **Все `.ds-tag`** (метки «Мотоцикл», «Квадрицикл», цена, FOV) — `flex-wrap: wrap; gap: 4px;`, внутри `.ds-card-main header` — `flex-direction: column; align-items: flex-start; gap: 6px;`, мета-теги переносятся на новую строку.
7. **Свотчи цветов** — `flex-wrap: wrap; gap: 8px;`, каждый свотч 24×24 (не меньше), подпись «Окраска» — отдельной строкой сверху.
8. **Слайдеры (range) в настройках** — на всю ширину, ползунок не меньше 20×20 для пальца. Заголовок слайдера (`.cam-slider-head`) — `flex-direction: column; align-items: flex-start; gap: 2px;`, чтобы значение не наезжало на подпись.
9. **Табы (`.ds-tabs`)** — `flex-wrap: wrap;`, каждый таб `flex: 1 1 calc(50% - 6px)` (2 в ряд) или `100%` при 5+ табах. Текст `font-size: 11px`, `white-space: nowrap; overflow: hidden; text-overflow: ellipsis;`.
10. **Карточки «Кнопки» / «Акселерометр»** (`.ctrl-mode-options`) — `grid-template-columns: 1fr 1fr;` или `1fr` на очень узких экранах (`max-width: 380px`). Превью 60×80 уменьшить до 48×64, текст описания — `font-size: 10px`.
11. **Экран аварии и критическое окно эвакуатора** — панель `width: calc(100% - 24px)`, кнопки `width: 100%`, статистика в одну колонку (`grid-template-columns: 1fr`), значения и подписи в одну строку с `justify-content: space-between`.
12. **Оверлей меню** (`#overlay.mode-main`) — на мобильном **без** горизонтального градиента слева; вместо этого — затемнение по всей площади `rgba(6,11,22,0.55)` снизу вверх, чтобы сцена с мотоциклом оставалась видна сверху. Панель меню — `align-self: flex-end; width: 100%`.

### Игровой HUD на мобильном (вертикально)
