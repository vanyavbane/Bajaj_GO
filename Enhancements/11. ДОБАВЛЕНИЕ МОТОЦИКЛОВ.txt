# ПРОМПТ: ДОБАВЛЕНИЕ НОВЫХ МОТОЦИКЛОВ В BAJAJ GO

Ты — опытный разработчик браузерных 3D-игр на Three.js. Перед тобой **актуальный рабочий HTML-файл игры bajaj GO** (мотоциклетный/квадроциклетный раннер в voxel-стилистике, собранный в один файл со встроенным Three.js r160, с кокпитом, физикой, экономикой, погодой, магазином, тюнингом, биомами).

Твоя задача — добавить **7 новых мотоциклов** в существующий каталог `r.bikeCatalog`, сохранив всю игровую логику и не сломав ни одну из работающих систем.

---

## Жёсткие требования


1. **Не ломай** существующее: каталог `r.bikeCatalog` (7 машин), магазин, гараж, тюнинг (`r.tuningCatalog`), экономику, физику (`Qm`, `e0`), кокпит, 3-е лицо, камеру (`Um()`), биомы, погоду, звуки, `localStorage`.
2. **Автопилот не добавлять** — только ручное управление.
3. Все новые мотоциклы должны пройти полный путь: покупка в магазине → выбор → заезд → тюнинг → сохранение → восстановление после перезагрузки браузера.

## 1. Новые модели в `r.bikeCatalog`

Сейчас в каталоге: `ns125` (127 км/ч, 0 ₽), `ns200` (140, 1000 ₽), `n250` (155, 1500 ₽), `dominar400` (180, 3000 ₽), `dominar1000` (380, 10000 ₽), `qute`, `qute_yura`.
Изменить цену ns125 - 850 рублей, далее от его цены рассчитывается цена остальных мотоциклов (указано дальше по ТЗ). 

Добавь ещё 7 записей в `r.bikeCatalog` со следующими параметрами. **Все цены считать относительно цены Pulsar 125 NS (стартовый мотоцикл — 0 ₽; в текущей игре `ns125` имеет `price: 0`, но упоминай его цену как "базовую" для расчёта по условиям ниже — уточняй в комментарии, что "дороже/дешевле на N рублей" от `ns125 = 0 ₽` даёт итоговую цену N ₽, если это подразумевается).**

> **Важно:** из-за того, что `ns125` в текущей игре бесплатный, все относительные цены следует пересчитать так, чтобы новые байки встали в разумную шкалу рядом с уже существующими (`ns200 = 1000`, `n250 = 1500`, `dominar400 = 3000`, `dominar1000 = 10000`). ### 1.1 Обязательные поля каждой новой записи

Скопируй структуру существующей записи (например, `ns125`) и заполни:

```js
{
  id: 'boxer100es',
  name: 'Bajaj Boxer 100 ES',
  vType: 'bike',
  typeLabel: 'Мотоцикл',
  maxSpeed: 90,
  price: 0,
  color: 0x1a1a1a,      // тёмный корпус
  accent: 0xd4a017,     // жёлто-охристый акцент
  accel: 18,            // <= 22, самый медленный
  massFactor: 1,
  hudStyle: 'round'     // круглый спидометр + одометр
}
```

- `accel` (базовое ускорение) подбирай монотонно по возрастанию скорости: 90 < 110 < 127 < 130 < 132 < 135 < 155. Пример: `boxer100es = 18`, `boxer125 = 22`, `boxer150 = 26`, `pulsar150ns = 27`, `pulsar180 = 28`, `avenger220 = 30`, `dominar250 = 36`.
- `hudStyle: 'round'` — флаг, по которому `updateCockpitDashboard` рисует **круглый** спидометр + одометр вместо стандартной панели. У `pulsar150ns`/`pulsar180`/`dominar250` оставь стандартную панель (`hudStyle: 'digital'`), у Boxer'ов и Avenger — `'round'` (у Avenger тоже можно поставить `'round'` для чоппер-стиля).

### 1.2 Визуальные модели

- **Boxer 100 / 125 / 150**: переиспользуй существующую геометрию мотоцикла из `bm()` с минимальными отличиями — другой цвет, проще обвес (нет агрессивных боковых накладок, простые крылья, одиночная фара). Ключевые отличия:
  - Один круглый передний фонарь вместо двойного у Pulsar.
  - Хромированный бак простой формы.
  - Простая выхлопная труба.
- **Pulsar 150 NS / 180**: переиспользуй кокпит и модель `ns125`/`ns200` — разные цвета/акценты, чтобы визуально отличались.
- **Dominar 250**: полностью аналогичен `n250`, но **корпус `0xa5d6a7`** (бледно-зелёный), акцент — более светлый.
- **Avenger 220** — **полностью новая модель** `avenger_build()`, отдельная от `bm()`. Требования:
  - **Низкое** сиденье (высота посадки ~0.35 м вместо 0.62 у Pulsar).
  - **Длинная вилка** с выносом вперёд на 0.35–0.5 м.
  - **Заднее крыло** с высокой спинкой пассажира (sissy bar), хромированное.
  - **Хромированные дуги** безопасности вокруг двигателя.
  - **Дутые крылья** спереди/сзади.
  - **Передняя фара** — большой круглый хром (диаметр ~0.28 м).
  - Один длинный выхлоп с правой стороны.
  - Цвет: глубокий чёрный (`0x0a0a0a`) с хромом; акцент — тёмно-красный (`0x8b0000`).
  - Кокпит: **чоппер-посадка** — руль выше и ближе к камере, длинные зеркала на высоких ножках, круглая приборка (`hudStyle: 'round'`).
  - В третьем лице — заметный силуэт чоппера.

Отдельно **в `bm()` добавь параметр `variant`** (например, `variant: 'boxer' | 'pulsar' | 'default'`), по которому строятся разные обвесы; для Avenger — отдельная функция `buildAvengerModel()` рядом с `Am()`.

## 2. Круглый HUD для Boxer'ов и Avenger

В `updateCockpitDashboard(now, speed, dist, score, laneMult, highBeamOn)` сейчас рисуется цифровая панель. Добавь **ветку по `hudStyle`**:

```js
const bike = r.selectedBike();
if (bike.hudStyle === 'round') {
  drawRoundDashboard(now, speed, dist, score, laneMult, highBeamOn);
  return;
}
```

`drawRoundDashboard` на том же `r.dashTex` (512×256, canvas) рисует:

1. **Круглый спидометр** (слева, диаметр ~210 px, центр `(128, 128)`):
   - Внешнее хром-кольцо (2-3 окружности).
   - Шкала 0…`bike.maxSpeed` с делениями через 10 км/ч.
   - Стрелка, плавно поворачивающаяся от -210° до +30° (сектор 240°) по значению `speed / maxSpeed`.
   - В центре — крупное число `Math.round(speed)`, ниже — «км/ч».
   - Дуга прогресса под шкалой, окрашенная в цвет акцента байка (`r.accentMat.color`).
2. **Круглый одометр** (справа, диаметр ~180 px, центр `(370, 128)`):
   - Внешнее хром-кольцо.
   - По кругу — цифры одометра (5 знаков), как на настоящем Boxer: значения `Math.floor(dist * 100)` — сотые доли км.
   - В центре — текущая дистанция в формате `000.00` км, крупный моноширинный шрифт.
   - Внизу — «ОБЩИЙ ПРОБЕГ» подпись.
3. **Между ними внизу** — строка с текущим балансом `score` (рубли) и множителем `×2` на встречке (красным).
4. **Дальний свет** — маленький индикатор (синяя точка) в верхней части спидометра при `highBeamOn`.
5. Стиль — **аналоговый, retro**: тёмно-серый фон (`#1a1a1a`), белая шкала, оранжевая стрелка (`#ff9800`), хром-рамки.

При смене мотоцикла в магазине (или в `applyCamProfileToCamera`, или в `syncVehicleAndCameraVisibility`) убедись, что HUD **перерисовывается** под новый `hudStyle` (сбросить кэш `m`/`_lastStamp` в `updateCockpitDashboard` или вызывать его принудительно).

## 3. Интеграция в магазин и гараж

- `renderShop` (`i()`) автоматически подхватит новые записи через `r.bikeCatalog.map(...)` — ничего не меняй.
- Проверь, что **свотчи цвета** (для `qute`/`qute_yura`) не появляются у новых байков — у них нет `swatches`, и это правильно.
- Блок «Цена»: у `boxer100es` — «Стартовый мотоцикл · Бесплатно», у остальных — `Цена: N ₽`.
- В карточке товара выводи `hudStyle` как бейдж: `Bi('Круглая приборка', 'warm')` для `round`, `Bi('Цифровая приборка', 'plain')` для `digital`.

## 4. Тюнинг и физика

- **Все новые байки наследуют `r.tuningCatalog`** через `r.getBikeEffectiveStats(id)` — тюнинг работает без изменений.
- `r.getUpgradePrice` использует `bike.price / 750` как множитель — при цене 0 это даст 0, что нормально для Boxer 100 ES; для остальных цены будут пропорциональны.
- **Тюнинг визуально**: `applyVisualTuningToModel` должен корректно работать для Avenger — проверь, что `e.fTire`, `e.frontFender`, `i.tuneBikeWindshieldCockpit` и т.д. либо переиспользуются, либо новый байк имеет собственный набор «слотов тюнинга».
- У Avenger с длинной вилкой **визуально расширь** зазоры, чтобы «дымчатое ветровое стекло» не висело в воздухе. Задай ему свой оффсет.

## 5. Экономика и сброс

- У новых байков **не обнуляй** существующую экономику (`bankPoints`, `fuel`, `wear`, `order`). Покупка новых — обычная транзакция.
- Проверь, что `r.ownedBikes` и `r.selectedBikeId` корректно принимают новые id.
- При первом запуске, если у игрока `ownedBikes = ['ns125']` и он никогда не покупал Boxer'ов — он их не увидит в «ВЫБРАТЬ». Это ок, покупка через магазин.

## 6. Камера и 3-е лицо

- `Um()` (камера) использует профили FOV/высоты на каждый байк через `r.getCamProfile(bike.id)`. Для новых байков оставь дефолтные `fov = 75`, `height = 0` — они подхватятся автоматически.
- Для **Avenger** рекомендуется `height: 0.15` (посадка ниже) и `fov: 78` — задай при инициализации каталога в `r.getCamProfile` (не через localStorage, а как дефолты).
- В **третьем лице** (`bikeThirdPersonBody`) для Avenger добавь **спинку пассажира** (sissy bar) и длинную вилку — это часть новой модели.
- У Boxer'ов в третьем лице — упрощённый силуэт, без агрессивных накладок, задняя овальная фара (овал горизонтальный).

Рекомендую **второй вариант**: `boxer125 = 0 ₽` как альтернативный стартовый, `boxer100es = 0 ₽`, оба бесплатные — разные стартовые байки.

12. При переключении байка в магазине HUD **сразу перерисовывается**.
13. Тюнинг применяется к новым байкам и визуально отображается.
14. Камера кокпита/3-го лица для Avenger не «виснет в воздухе», длинная вилка и руль на месте.
15. Дальний свет (F), перестроения трафика, `near miss`, прыжки с трамплинов — работают на новых байках.

19. `?debug` и `window.__bajaj.snapshot()` показывают корректный `bike` id.
20. Старые сохранения (без новых id) не крашат игру: `ownedBikes` дополняется дефолтами, `selectedBikeId` валидируется.

## 9. Структура правок (кратко)

- **`Nm()`** — добавить 7 записей в `r.bikeCatalog` с полями `id/name/vType/typeLabel/maxSpeed/price/color/accent/accel/massFactor/hudStyle`.
- **`Am()`** — добавить параметр `variant` в `bm()`, добавить `buildAvengerModel()`, расширить `r.applyVisualTuningToModel`.
- **`Um()`** — дефолтные FOV/height для новых байков (через проверку при `getCamProfile`).
- **`L()` в `Um()`** (`updateCockpitDashboard`) — ветка `hudStyle === 'round'` → `drawRoundDashboard`.
- **`B0()` (`renderMainMenu` / `renderShop`)** — без изменений (каталог подтянется автоматически), только добавить бейдж «Круглая/Цифровая приборка».
- **`vm()` (`updateEcoHud`)** — без изменений.
- **`s()` в `Am()` (`applyVisualTuningToModel`)** — не сломать на новых моделях.
- **`localStorage`** — новые id подхватятся через `r.ownedBikes.push(id)` в существующей `purchaseUpgrade`-логике магазина.

**Главный принцип:** не переписать игру, а **аккуратно расширить** каталог, добавить 1 новую модель чоппера и 1 новый стиль HUD. Всё остальное — работает как есть. Выдай готовый файл `bajaj_GO_v19.html` целиком.
