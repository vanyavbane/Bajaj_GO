# Промпт: доработка декора биома «Лес»

---

## Контекст

Игра `bajaj-go.html` на Three.js — раннер на мотоцикле по процедурно генерируемым биомам. Биом «Лес» сейчас выглядит разреженно и неестественно. Нужно сделать плотный, естественный лес с большим количеством деревьев и кустов разного типа и высоты.

---

## Часть 1. Деревья

### 1.1. Типы деревьев (обязательно все три)
- **Берёзы** — светлые стволы с характерными чёрными отметинами, рыхлая/светлая крона.
- **Ели** — конусообразные, тёмно-зелёные, ярусная крона.
- **Сосны** — высокие стволы с кроной в верхней части, «зонтиком».

### 1.2. Количество и плотность
- Деревьев должно быть **очень много** — плотное расположение объектов в биоме, лес должен выглядеть густым и естественным, а не разреженным.
- Плотность задать в конфиге (`FOREST_TREE_DENSITY`), с возможностью тюнинга; целевой ориентир — визуально плотный лес, где деревья образуют «стену» по сторонам трассы.
- Соотношение типов — примерно равномерное, с небольшим случайным разбросом (например, берёзы 35%, ели 35%, сосны 30%), чтобы лес не выглядел однородным.

### 1.3. Разная высота
- Деревья должны быть **разной высоты** — от низких молодых до высоких взрослых.
- Задать диапазон масштаба (`TREE_SCALE_MIN` … `TREE_SCALE_MAX`) и применять случайный масштаб к каждому экземпляру.
- Высота должна варьироваться и **внутри одного типа** (низкая берёза, высокая берёза и т.д.), а не только между типами.

### 1.4. Естественность
- Случайное вращение по Y для каждого дерева (чтобы не было одинаковых «клонов»).
- Небольшой случайный наклон (лёгкий, чтобы не выглядело как ряд).
- Случайное смещение позиций (jitter), чтобы не было строгой сетки.
- Не допускать пересечения стволов/крон друг с другом в явном виде (минимальная дистанция между деревьями).

---

## Часть 2. Кусты

### 2.1. Типы и разнообразие
- Кусты **должны быть** в биоме, разных типов:
  - **высокие** кусты (до уровня пояса/груди райдера);
  - **низкие** кусты (у земли);
  - **разные** по форме/цвету — несколько вариантов, чтобы не выглядели одинаково.

### 2.2. Количество и высота
- Кустов тоже **много** — они заполняют пространство между деревьями и у дороги.
- Кусты **разной высоты** (`BUSH_SCALE_MIN` … `BUSH_SCALE_MAX`), случайный масштаб на каждый экземпляр.
- Случайное вращение и jitter позиций, как у деревьев.

---

## Часть 3. Расположение и правила

### 3.1. Плотность и естественность
- Деревья и кусты располагаются **плотно**, образуя густой лес по обе стороны трассы.
- Композиция: ближе к дороге — кусты и низкие деревья, дальше — высокие деревья (но без строгой закономерности, с элементом случайности).
- Лес должен выглядеть **естественно**: без рядов, без одинаковых объектов, с разной высотой и типами.

### 3.2. Запрет на дорогу
- Деревья и кусты **не спавнить на проезжей части** и в коридоре дороги (включая обе ветки развилки) — сохранить существующее правило из общего ТЗ (п. 1.3 «лишние декорации на дороге»).
- Проверка пересечения bounding box/радиуса с коридором дороги перед спавном.

### 3.3. Согласование с общими правилами
- Не «скакать» при смене биома (см. общее ТЗ п. 1.1): позиции в мировых координатах, новые объекты спавнятся за камерой.
- Декорации нового биома видны сразу при входе (preload моделей/материалов, спавн заранее — общее ТЗ п. 1.5).
- При плотном лесе — следить за производительностью: использовать **instancing** (InstancedMesh) для деревьев/кустов одного типа, LOD и ограничение дальности отрисовки/тумана.

---

## Часть 4. Конфиг (вынести параметры)

```
FOREST_TREE_DENSITY      // плотность деревьев
FOREST_BUSH_DENSITY      // плотность кустов
TREE_TYPE_RATIO          // { birch, spruce, pine }
TREE_SCALE_MIN/MAX       // диапазон высоты деревьев
BUSH_SCALE_MIN/MAX       // диапазон высоты кустов
TREE_MIN_SPACING         // мин. дистанция между деревьями
JITTER_AMOUNT            // случайное смещение позиций
TILT_MAX                 // макс. случайный наклон
```

---

## Часть 5. Критерии приёмки

1. В биоме «Лес» **очень много деревьев** — лес выглядит плотным и густым, а не разреженным.
2. Присутствуют **все три типа деревьев**: берёзы, ели, сосны — в примерно равных пропорциях со случайным разбросом.
3. Деревья **разной высоты** (и внутри типа, и между типами), с случайным масштабом.
4. Кусты присутствуют, **разных типов** (высокие, низкие, разные по форме), **разной высоты**, в большом количестве.
5. Лес выглядит **естественно**: без рядов, с случайным вращением/наклоном/jitter, без явных пересечений.
6. Деревья и кусты **не стоят на дороге** и в коридоре развилки.
7. Нет «скачков» декора при смене биома; новые объекты видны сразу при входе в биом.
8. Производительность не проседает (instancing/LOD/туман).
